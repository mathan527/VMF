Fidelity statement

The Virtual Mobile Farm detects crashes, hangs/ANRs, layout defects and performance regressions of an APK across 24 controlled virtual Android profiles. Each profile reproduces the Android version, screen, RAM, CPU tier and known OEM behaviour patterns of a named reference model. It does not reproduce OEM firmware, physical GPU/chipset performance or hardware sensors. Performance results are relative measurements within the virtual environment.
